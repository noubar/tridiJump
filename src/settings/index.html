    Provider setup / credentials

    Use your own free API credentials. Stored locally in this browser profile and sent only to their provider; never synchronized or exported. Extension local storage is not an encrypted credential vault. Removing a key here does not revoke it at the provider.

    Cults3D

    Sign in and create a read-only API key. Enter your nickname and key, never your password. Official API guide

    MyMiniFactory

    Sign in, open Developer settings, create an application and copy its API key. Use the API key, not the client ID or client secret. Official developer guide

    MyMiniFactory's documented authentication sends the key in the API request URL. tridiJump never includes it in native-search links, history or error messages.

    Thingiverse

    Sign in, open My Apps, create an application and copy its App Token. Do not use its client secret or a browser session token. Official developer guide
