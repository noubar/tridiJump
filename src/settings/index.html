    Provider setup / credentials

    These providers require API authentication for searches. Obtain your own free credentials using their official guides below. tridiJump does not provide or proxy credentials and has no server receiving them.

    Saved credentials stay in this browser profile's extension local storage and are sent only to the corresponding repository; never synchronized or exported. Local storage is not an encrypted password vault. Saved secrets are never redisplayed. Use Remove credentials at any time to delete them locally; this does not revoke them at the provider.

    Cults3D

    Cults3D authenticates API requests with your nickname and key. Sign in and create a read-only API key. Enter your nickname and key, never your password. Official API guide

    MyMiniFactory

    MyMiniFactory requires an authenticated API client. Sign in, open Developer settings, create an application and copy its API key. Use the API key, not the client ID or client secret. Official developer guide

    MyMiniFactory's documented authentication sends the key in the API request URL. tridiJump never includes it in native-search links, history or error messages.

    Thingiverse

    Thingiverse's developer API uses an application App Token. Sign in, open My Apps, create an application and copy its App Token. Do not use its client secret or a browser session token. Official developer guide
