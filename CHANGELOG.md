# Changelog

## 1.0.0 — 2026-10-29

- First public Chromium Manifest V3 release.
- Unified progressive search for Printables, Thingiverse, MyMiniFactory and
  Cults3D, with native-search fallbacks for MakerWorld and Thangs.
- User-driven pagination, repository and price/format filters, honest sorting,
  and bounded offline English/German Expanded Search.
- Local provider setup, optional search history, and System/Light/Dark themes.
- GPL-3.0-or-later source with bundled lexical-data licenses and attribution.
