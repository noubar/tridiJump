# Changelog

## 1.1.0 — 2026-11-02

- Added immediate aggregated search for Sketchfab through its official public
  Data API v3.
- Added optional Smithsonian 3D aggregated search with a user-supplied API key
  and an optional bundled NASA 3D catalog.
- Added native direct-search entries for CGTrader, Creality Cloud and YouMagine
  where a suitable public aggregation interface is not currently available.
- Added and hardened Chromium/Firefox release and adaptive store-screenshot
  automation without adding screenshot-only code to production builds.
- Refined repository availability, setup-required handling, result filtering,
  pagination, documentation and cross-browser UI behavior.

## 1.0.0 — 2026-10-29

- First public Chromium Manifest V3 release.
- Unified progressive search for Printables, Thingiverse, MyMiniFactory and
  Cults3D, with native-search fallbacks for MakerWorld and Thangs.
- User-driven pagination, repository and price/format filters, honest sorting,
  and bounded offline English/German Expanded Search.
- Local provider setup, optional search history, and System/Light/Dark themes.
- GPL-3.0-or-later source with bundled lexical-data licenses and attribution.
