# V2 Phase 2C: NASA 3D

NASA 3D is implemented as the first official local-catalog provider. The runtime
extension searches 333 normalized resources derived from NASA's official 3D
Resources repository at pinned commit
`11ebb4ee043715aefbba6aeec8a61746fad67fa7`.

The integration adds no host permission, credential, API request, scraper,
backend or downloaded model asset. It keeps NASA as a specialist source so the
existing general-repository experience remains intact. See the complete
[source, mapping, maintenance and usage record](providers/nasa.md).
