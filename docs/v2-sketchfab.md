# V2 development: Sketchfab

Sketchfab is the first V2 provider addition. It adds anonymous official Data API
v3 aggregation, cursor pagination, normalized public metadata, fixed-origin
request validation, automated fixtures and an optional live smoke test. It adds
no credentials, OAuth flow, download API, scraping, backend, runtime dependency,
analytics or telemetry. See [the provider record](provider-sketchfab.md).

This development note is separate from the V1.0.0 release notes, which remain
unchanged.
