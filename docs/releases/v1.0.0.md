# tridiJump v1.0.0

## First public release

tridiJump provides one browser-extension interface for searching several
3D-model repositories. Results arrive progressively and open on their original
repository pages.

## Included

- Aggregated search across four providers
- Direct-search support for MakerWorld and Thangs
- Progressive provider results and isolated provider failures
- Repository, Free/Paid, and available-format filters
- Honest sorting based only on metadata providers return
- User-driven Load more pagination
- Bounded offline Expanded Search using English synonyms and English/German data
- Local settings and optional local search history
- Local user credential setup for providers that require free API access
- System, Light, and Dark themes
- Open-source GPL-3.0-or-later distribution

## Providers

Aggregated results:

- Printables — works immediately
- Thingiverse — requires the user's provider App Token
- MyMiniFactory — requires the user's provider API key
- Cults3D — requires the user's provider nickname and read-only API key

Native direct search:

- MakerWorld
- Thangs

## Privacy

tridiJump has no backend, account, analytics, telemetry, ads, or affiliate
rewriting. Settings, optional history, and provider credentials stay in extension
local storage. User-initiated queries and each provider's own credentials are sent
directly to that provider over HTTPS. Extension local storage is not an encrypted
password vault. See [the privacy policy](../../PRIVACY.md).

## Known limitations

- Chromium and Chrome-compatible Manifest V3 browsers are the V1 target.
- MakerWorld and Thangs return native-search links rather than aggregated cards.
- Provider metadata varies, so some cards cannot be classified or sorted by every
  optional field.
- Provider APIs, credential issuance, quotas, and undocumented Printables schema
  remain external dependencies.
