# tridiJump v1.1.0

## Provider and cross-browser update

tridiJump 1.1.0 expands the repositories available from the unified search
interface while preserving the lightweight Manifest V3 architecture and local
credential policy.

## Highlights

- Sketchfab aggregated search through the official public Data API v3
- Optional Smithsonian 3D search using the user's own API key
- Optional local NASA 3D catalog, disabled by default
- Native direct search for CGTrader, Creality Cloud and YouMagine
- Improved setup-required, filtering and pagination behavior
- Chromium and Firefox release automation
- Adaptive local store screenshots generated from the real production pages

## Repository availability

Works immediately or locally once enabled:

- Printables
- Sketchfab
- NASA 3D

Requires the user's own provider credentials:

- Cults3D
- MyMiniFactory
- Thingiverse
- Smithsonian 3D

Native direct search:

- MakerWorld
- Thangs
- CGTrader
- Creality Cloud
- YouMagine

## Privacy

tridiJump has no backend, tridiJump account, analytics, telemetry or advertising.
Provider credentials and optional history stay in extension local storage. Local
extension storage is not an encrypted password vault. Direct-search providers
receive the query only when their native-search link is opened.
