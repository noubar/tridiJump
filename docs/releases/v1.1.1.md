# tridiJump v1.1.1

Release date: 2026-11-16

This maintenance release makes repository selection accurately reflect local
provider setup. Cults3D, MyMiniFactory, Thingiverse and Smithsonian 3D are not
selectable or searched while their required user credentials are absent. Each is
clearly linked to its Settings configuration section.

Saved repository preferences remain separate from credential presence. Adding a
key makes the provider selectable without overriding an explicit disabled choice;
removing a key immediately makes it unavailable and cancels any active request.
Authentication rejection remains a provider-isolated failure with an actionable
message and is distinct from missing setup.
